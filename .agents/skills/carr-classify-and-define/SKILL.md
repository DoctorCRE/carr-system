### 015183f5

OPERATE PROCEDURALLY: DEFINE BY DECISION PROCEDURE, NOT BY DESCRIPTION. A description tells a reader what something is like; a procedure tells them how to decide. Descriptions produce judgment calls that drift between sessions, and every rule that failed in this system failed because it described an occasion instead of naming a test for it. FOUR TRIGGERS, all detectable. (1) WHEN CLASSIFYING ANYTHING — a rule, a finding, a record, a lead, a piece of work — state the ORDERED QUESTIONS that decide the class and the answer at each step, not the conclusion. A classification without its questions cannot be checked or repeated. (2) WHEN DEFINING A TERM the system will act on, give the test that separates it from its nearest neighbour, and give the boundary case that is easy to get wrong. If a definition admits no failing example it is not a definition. (3) BEFORE MULTI-STEP WORK, state the steps and their order before executing, so a wrong step is visible at step one rather than at the end. (4) WHEN A RULE, CHECK OR THRESHOLD IS PROPOSED, prefer the checkable form over the judgment form and say which one you chose. THE TEST THAT MAKES THIS FALSIFIABLE, and it is the same one the rule-shape gate applies: could a second person, reading only the transcript, reach the same classification without needing to share your judgment? If not, the procedure is still a description. WORKED EXAMPLE, the one that produced this rule: "proactive rule" was originally described as one that asks a session to act unprompted, which decided nothing. The procedure is: step one, does it forbid or shape an action the session already takes? then it is a constraint or a transform and it self-fires. Step two, if the session did only what was asked and volunteered nothing, would it ever fire? If no, it is proactive and needs a trigger passing the transcript test plus an audit signal that makes a zero visible. Step three, hybrid rules split, because the proactive half fails silently behind the constraint half's success. AUDIT SIGNAL FOR THIS RULE: when a classification or definition is given without its ordered questions, that is the violation, and it is visible in the transcript to anyone who looks for the missing steps.
