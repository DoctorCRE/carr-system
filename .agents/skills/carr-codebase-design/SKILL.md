### a8c55a47

A MANUAL PATH AND AN AUTOMATED PATH THAT DO THE SAME JOB MUST BE THE SAME CODE. When a script already performs an operation correctly, documentation and sessions call THE SCRIPT — never re-document the raw command it wraps, because the wrapper carries the part people forget and the two copies drift silently while both keep looking like they worked. TRIGGER: before writing a command into a doc, SOP, task file, or chat instruction, check whether a script in bin/ or ops/ already runs it. If one does, name the script. If none does and the command needs a flag, env var, or ordering to be correct, write the script first and name that. GENERAL FORM: any operation with two implementations has two contracts, and the one nobody exercises is the one that rots — the failure is always silent, because each path independently reports success. COROLLARY: when the duplication cannot be removed, something must COMPARE the two; prefer deleting the second path, and where it must exist, add the comparison with a visible row.
