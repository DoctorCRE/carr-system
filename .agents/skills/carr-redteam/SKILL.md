### 81709f57

A RED TEAM ASSIGNS DISTINCT LENSES, NEVER REDUNDANT VOTES — and one seat re-runs the evidence instead of arguing the conclusion.

WHY, and the evidence is this system's own: three instances of the same model family reviewing one claim are CORRELATED, not independent. On 2026-08-02/03 a single session produced FIVE wrong claims in one night and every one of them was an assertion that something did not exist — no such verb, no such scheduled job, four decisions unruled, Drive could never be retired. A second or third instance would have confirmed all five, because each would have searched the same partial collection the same wrong way and found the same nothing. On the same night a concurrent session holding full system context filed an entire audit into an empty scaffold repo. Agreement between models is not verification. It is the same prior, counted twice.

SO COMPOSE FOR DIVERSITY, the way the Deal Council already does. That panel does not run N identical reviewers; it runs a lender, a contractor, an attorney, a skeptic, a landlord and a listing agent, because perspective diversity catches failure modes redundancy structurally cannot. Any red team convened anywhere in this system inherits that shape: name each seat's lens before it runs, and never convene two seats that would fail the same way.

THE MANDATORY SEAT, and it exists because of the failure above: one seat's job is to RE-RUN THE EVIDENCE, not to evaluate the argument. It goes back to the source, re-runs the query, and checks whether the claim's foundation was ever actually established — because an error of OMISSION is invisible to a panel debating the claim, given the claim is never the flawed part. The search behind it is. That seat carries rule 2b889e80 (no negative finding from a single collection — name the parallel collections and check every one) and rule d5dcfe26 (a dated memo is not self-updating; find a decision by what it DOES, never by its label). IT IS SCORED ON WHETHER IT RE-RAN THE QUERY, NOT ON WHETHER IT AGREED. A seat that reports "I concur" without having independently reproduced the evidence has not done this job.

WHEN A RED TEAM IS CONVENED AT ALL: when the deciding seat is unsure, before anything irreversible, and — in away mode — as the CEO session's standing move whenever the admin and COO seats disagree, or whenever they agree on something nobody checked.
