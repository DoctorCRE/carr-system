### def3e84e

Artifact tombstones: nothing silently rots. A superseded gallery artifact gets OVERWRITTEN with the red "_TO_DELETE" page and a description prefix saying so, and the deletion is queued with add-loop rather than by hand-editing any file. Redirect stubs are the exception, because a stub that still points somewhere useful is not rot. The principle generalises past the gallery: a superseded thing that merely stops being updated looks identical to a current one, and a reader cannot tell them apart — so superseding is an ACT, with a visible marker and a queued cleanup, never an omission.
