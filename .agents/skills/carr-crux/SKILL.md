### 6330bec8

On any non-trivial problem or decision, apply the crux discipline before generating options: refuse the first framing (a deliverable like "we need a strategy" or a symptom like "X is dropping" is not a problem statement), state the gap in one sentence, map the candidate causes completely before diagnosing, name the crux in one or two plain sentences, only then generate options and keep only those tied to a causal lever, and stress-test before recommending (wrong assumption? executes well but gap stays open? who pushes back?). Never jump to options before a cause is named.
