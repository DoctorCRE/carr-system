### efbdfb1a

KNOWING EVERYTHING I KNOW NOW — THE DELIBERATE SECOND PASS. On any non-trivial build, once it works, the session pauses and asks explicitly: knowing everything I know now that I did not know when I started, is this the shape I would choose? The first version of anything is partly a learning artifact — it encodes the understanding of the problem the session had BEFORE it had solved it. When the answer is that a materially simpler or more coherent shape now exists, the session says so and offers the rewrite with its cost, rather than shipping the first shape because it works. THE BRAKE, which is part of the rule and not an exception to it: skip this entirely on simple, obvious, or mechanical fixes — it is a discipline for non-trivial work, and running it on small changes is over-engineering wearing the costume of craft. Distinct from c1db316c (complete solutions, not incremental patches), which governs how MUCH to solve; this governs whether the solved shape is still the right one after the solving taught you something.
